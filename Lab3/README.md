# Лабораторная работа 3 — Manga API

API реализует CRUD-операции для мангак, манги и жанров.

Связи между таблицами:

- один мангака может создать много манги;
- одна манга может иметь много жанров;
- один жанр может использоваться во многих произведениях.

## Запуск

```powershell
dotnet restore
dotnet run
```

API запускается по адресу:

```text
http://127.0.0.1:5073
```

Примеры запросов находятся в файле `MangaApi.http`.

При первом запуске автоматически создаётся SQLite-база `manga.db`.
